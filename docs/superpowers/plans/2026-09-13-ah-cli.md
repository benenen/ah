# ah CLI Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent modules and review; execute continuously under the user's instruction to implement the existing contract.

**Goal:** Deliver the Go SSH connection CLI, TOML CRUD, SFTP remote-to-remote copy and remote path completion.

**Architecture:** CLI consumes config and SSH clients; transfer and completion reuse SFTP connections. Copy streams through the local process to a temporary remote file and publishes it only after successful close.

**Tech Stack:** Go, Cobra, go-toml/v2, x/crypto/ssh, pkg/sftp, x/term, gofrs/flock.

**Spec:** docs/agents-dot-md/requirements.md and architecture.md (approved by “开始按照这个实现代码”).

## Global constraints

- Work in the current checkout so the initialized untracked project contract remains available; retain user files, do not commit or publish automatically.
- TOML contains no passwords; known_hosts verification is mandatory. Completion is noninteractive and bounded to three seconds.
- Go module path follows origin: github.com/benenen/ah. Versions are pinned by go.mod/go.sum after resolving dependencies.
- Default copy refuses existing targets; --force uses atomic POSIX rename and fails safely if unsupported. Source is a regular file. Destination directories accept the source basename.
- Validate with local controlled SSH/SFTP servers, never production hosts.

## Completion record

All four tasks implemented. Real local SSH/SFTP tests cover trusted/unknown/changed keys, agent and encrypted identities, lock/handshake/I/O cancellation, PTY restoration, remote copy and failure protection. Bash and Zsh PTY tests cover alias plus both remote paths, UTF-8, whitespace, literal shell metacharacters and opening single/double quotes. Final verification commands and limitations are documented in README.md.

Ruling: require the hard-link extension for default atomic no-clobber publication because ordinary rename behavior differs across SFTP servers. Force requires POSIX rename. Unknown extensions fail safely instead of risking an existing target.

Ruling: add small Cobra shell compatibility overrides after actual PTY tests exposed Bash 3 dependency/UTF-8 issues and Zsh backslash/open-quote handling. Keep regressions alongside generated script integration tests.

Changes remain in the user's checkout, uncommitted; no merge, push or publication performed.
