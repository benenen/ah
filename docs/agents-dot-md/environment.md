# 开发环境

> 配置测试环境、凭据或发布流程时读取。

Go 版本以 go.mod 为准，构建产物放 bin/。当前未配置 CI 或发布流水线。测试会自行启动本地 SSH/SFTP 服务，无需配置外部服务器。

真实连接 TOML、SSH 私钥及 known_hosts 放在仓库外；测试使用临时目录及虚构连接，示例仅使用 example.com 等示例地址。开发机与目标主机的认证材料不写入文档。

配置默认路径及权限以 requirements.md 为准。集成测试自行启动受控 SSH/SFTP 服务并清理资源；依赖外部条件的检查须明确报告是否执行。

端到端测试 `make e2e` 依赖本机 Docker，镜像构建需能访问 Alpine 软件源（首次构建后使用缓存）。镜像内 ops 用户的密码与运行时生成的密钥均为一次性测试数据，只存在于临时容器和临时目录，不代表任何真实凭据。
