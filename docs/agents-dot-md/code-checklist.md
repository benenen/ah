# Go 代码检查清单

> 写或审 Go 代码时读取；按改动适用项验证。

- error 保留 `%w` 错误链；检查读写和关闭错误，失败返回非零退出码。
- 网络操作传递 context，配置连接超时；取消须能解除阻塞 I/O，每个 goroutine 有退出与回收路径。
- 文件、SSH session、SFTP client、SSH client 明确所有权，成功、失败和取消均释放。
- CLI 输出与底层逻辑分离，诊断写 stderr；补全 stdout 仅包含协议要求的候选信息。
- TOML 解析及校验失败不修改原文件；写入保持受限权限，原子替换并防止并发丢失修改。
- 认证资料不进入输出、测试快照或版本控制；真实 SSH 主机连接不得跳过主机密钥验证。
- 跨远端复制使用流式 I/O，处理部分写入、断线、已有目标与中途取消。
- 远程路径用 POSIX 语义，本机路径用 filepath；列目录通过 SFTP，避免 shell 拼接。
- 补全覆盖两端、目录尾斜线、空格及中文；短超时且不触发交互认证。
- 按需定义小接口；共享 map、slice 等状态明确并发边界。
- 运行 gofmt、构建、测试和 vet；涉及并发时补充 race 检查。
- 测试覆盖配置 CRUD/损坏、端点解析、复制失败/取消以及补全过滤等行为边界，避免仅复述实现。
